# Castle Protect: Project Brief

## Goal
Build the best single-player castle artillery game in its category. Turn-based (or hybrid) artillery play in the spirit of
Pocket Tanks (angle + power shots, many fun weapons, destructible terrain) mixed with castle building / defending ideas
seen in Castle Clashers / castle buster style mobile games.

## Hard requirements
- 1 player only. No multiplayer. Opponents are AI.
- Must play fully offline (no server needed for any core feature).
- Platforms: iOS, Android, Web (one codebase preferred).
- Fun units, fun tech tree, fun weapons, fun enemies, fun maps, missions and levels.
- Original game: draw on genre mechanics only. Do NOT copy names, characters, art, music, levels or look of any existing game.
  All weapon, unit, enemy, world and character names must be original.

## Process
1. Research (market, reference teardown, code survey, tech stack) -> docs/research/
2. Design (core loop, weapons and tech tree, units, enemies, campaign, art, UX/audio) -> docs/design/, art -> docs/art/
3. Review and cross-check -> docs/review/
4. Master plan -> docs/PLAN.md. Owner approves before any code is written.

## Writing style for all docs
Plain, short words. Active voice. No em dashes. No stock phrases or cliches. Cut needless words.
